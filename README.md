# Apps

Przed uruchomieniem aplikacji, ustawić adres IPv4 na IP:192.168.1.20 z maską:255.255.255.0, a adres rozgłoszeniowy na 192.168.1.120.
W samym kodzie aplikacji ClientApp nie trzeba nic zmieniać, chyba że zmianie ulegnie adresacja IP. 
Jeśli wprowadzona zostanie zła adresacja IP, komunikacja aplikacji ClientApp i ServerApp nie będzie możliwa lub będą zwracane błędy w polach
odnośnie statusów
